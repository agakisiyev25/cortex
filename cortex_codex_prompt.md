## 1. What we are building

**CorteX** is a voice-controlled AI co-pilot for the operating room. A surgeon with sterile hands speaks; CorteX shows patient data, scrolls through the patient's MRI, rotates and filters a patient-specific 3D model of the brain and tumor, runs the WHO safety time-out, checks drugs against allergies and writes the operative report. Output appears as panels on a web "OR console" plus short spoken replies.

- Event: Replit AI & Dev Hackathon Baku. Final app is deployed on **Replit**.
- Demo case: one brain-tumor patient (MRI + tumor segmentation mask). The repo must also work out of the box with a **synthetic** case generated by a script.
- Base code: **ORION** (Gemini Live Agent Challenge winner), source at `https://github.com/40tify/orion`. We keep its architecture: FastAPI + Google ADK backend, Gemini Live API over WebSocket, vanilla HTML/JS frontend, Three.js r128 3D viewer, canvas PNG slice viewer, tools that return a `render_command` which the frontend renders.

## 5. Implementation

### 5.1 Phase 1: case asset pipeline (new files)

#### `scripts/make_synthetic_case.py`

Creates a fake brain MRI and a 4-label mask so the app runs without real data.

- CLI: `python scripts/make_synthetic_case.py --out data/synthetic` → writes `image.nii.gz` (float32) and `mask.nii.gz` (uint8).
- Grid 160 × 192 × 160 voxels, 1 mm isotropic. Affine: `np.diag([1, 1, 1, 1])` with translation `[-80, -96, -80]` so the volume is centred on the origin, axes in RAS.
- Image: background 0. Brain = ellipsoid centred at the origin with radii (65, 80, 60) mm, intensity 0.55 plus Gaussian noise σ = 0.03 (seed 42). Two ventricles = ellipsoids centred at (±10, 5, 10) mm with radii (6, 22, 10) mm, intensity 0.25.
- Tumor in the right frontal lobe, centred at (+30, +35, +15) mm (RAS: +x right, +y anterior, +z superior):
  - label 1 `non_enhancing_core`: sphere r = 9 mm, intensity 0.30
  - label 3 `enhancing_tumor`: shell between r = 9 and r = 14 mm, intensity 1.00
  - label 2 `edema`: shell between r = 14 and r = 24 mm, intersected with the brain, intensity 0.75
  - label 4 `resection_cavity`: sphere r = 8 mm centred at (+30, +12, +15) mm, only where no other label is set, intensity 0.05
- Clip the image to [0, 1].

#### `scripts/build_case.py`

Turns one MRI volume + one label mask into everything the app needs.

- CLI:
  ```
  python scripts/build_case.py \
    --image PATH.nii.gz --mask PATH.nii.gz --out app/static/case \
    [--labels "1:non_enhancing_core,2:edema,3:enhancing_tumor,4:resection_cavity"] \
    [--case-id CASE-001] [--brain-mask PATH.nii.gz]
  ```
  The `--labels` default is exactly the string shown. Allowed structure names are only: `non_enhancing_core`, `edema`, `enhancing_tumor`, `resection_cavity`. Any other name → exit with an error.
- Load both with nibabel and apply `nib.as_closest_canonical`. Fail with a clear message if the image and mask shapes differ. If the image is 4-D, fail with a message asking for a single 3-D modality.
- Delete `--out` contents first (`slices/`, `case.json`, `model.glb`) so stale files never remain.

**Slices (axial PNGs):**
- Normalise the image: clip to the 1st and 99th percentile of non-zero voxels, scale to 0–255.
- For each k from 0 (most inferior) to nz−1: `sl = data[:, :, k]`, `m = mask[:, :, k]`. Display orientation is radiological: `disp = np.flipud(sl.T)[:, ::-1]`, same transform for `m`.
- Overlay: for each label pixel, blend the label colour at alpha 0.45 over the grey image. Colours (RGB): `enhancing_tumor` (226, 87, 76), `non_enhancing_core` (140, 132, 230), `edema` (224, 163, 59), `resection_cavity` (111, 168, 220).
- Resize to physical aspect using voxel sizes from `header.get_zooms()`: width ∝ nx·sx, height ∝ ny·sy, longest side 512 px, Lanczos.
- Draw a small white "R" 12 px from the left edge, vertically centred (patient right appears on screen left).
- Save as `slices/001.png` … zero-padded to 3 digits, slice 001 = most inferior.

**Landmarks (1-based slice numbers):**
- `tumor`: slice with the largest area of `enhancing_tumor ∪ non_enhancing_core`; if both are absent use `edema`; if all absent use `mid_brain`.
- `tumor_top` / `tumor_bottom`: highest / lowest slice containing any label except `resection_cavity` (fallback `tumor`).
- `resection_cavity`: slice with the largest cavity area. Include this key only if the label is present.
- `mid_brain`: middle slice of the brain extent (brain mask defined below).

**Volumes:** for each present label, voxel count × voxel volume (mm³) ÷ 1000 → cm³, rounded to 1 decimal.

**Brain mask:** if `--brain-mask` is given, use it. Otherwise, if more than 10 % of voxels are exactly 0 (skull-stripped data): `image > 0`. Otherwise: Otsu threshold (`skimage.filters.threshold_otsu`). In both automatic cases keep the largest connected component and fill holes (`scipy.ndimage.binary_fill_holes`).

**3D model (`model.glb`):**
- For `brain` and each present label (skip labels with fewer than 50 voxels): Gaussian-smooth the binary mask (σ = 1.0), then `skimage.measure.marching_cubes(level=0.5, step_size=2)` for `brain`, `step_size=1` for labels.
- Vertices to millimetres: `nib.affines.apply_affine(affine, verts)`, then convert RAS to Three.js axes: `three = np.column_stack([-ras[:, 0], ras[:, 2], ras[:, 1]])` (y = superior is up, anterior faces the default camera).
- One `trimesh.Trimesh` per structure with `trimesh.visual.TextureVisuals(material=trimesh.visual.material.PBRMaterial(baseColorFactor=[r, g, b, 255], metallicFactor=0.0, roughnessFactor=0.8))`. Brain colour (201, 210, 218); label colours as above.
- `scene = trimesh.Scene()`; `scene.add_geometry(mesh, node_name=name, geom_name=name)` for each; `scene.export(out / 'model.glb')`.
- Re-load the GLB with `trimesh.load` and print the geometry names as a check.

**`case.json`** (exact keys):
```json
{
  "case_id": "CASE-001",
  "source": {"image": "<image filename>", "mask": "<mask filename>",
             "label_map": {"1": "non_enhancing_core", "2": "edema", "3": "enhancing_tumor", "4": "resection_cavity"}},
  "slices": {"count": 0, "base_url": "/static/case/slices", "pad": 3, "plane": "axial", "order": "inferior_to_superior"},
  "landmarks": {"tumor": 0, "tumor_top": 0, "tumor_bottom": 0, "mid_brain": 0},
  "volumes_cm3": {"enhancing_tumor": 0.0, "non_enhancing_core": 0.0, "edema": 0.0, "resection_cavity": 0.0},
  "structures": ["brain", "enhancing_tumor", "non_enhancing_core", "edema", "resection_cavity"],
  "model_url": "/static/case/model.glb"
}
```
`volumes_cm3` and `structures` contain only what is present (`brain` is always present). `landmarks.resection_cavity` appears only if present.
